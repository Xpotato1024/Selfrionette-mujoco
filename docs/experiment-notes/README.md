# experiment note

個別実験のcondition、unit、model version、実行command、observed resultを記録する。観測していない結果を推測で
再構築しない。このdirectoryはcanonical architecture仕様ではない。

継続的な実装事実、実験的価値、未検証事項、研究判断は`research/README.md`に従ってmonthly logへ記録する。
experiment noteは個別条件と観測evidence、research logは時系列の判断とclaim boundaryを担当する。
